# BCI Report — site

English static EEG evaluation workbench. All numbers come from `src/data/mvp.json`,
which the parent pipeline exports after independent review; the page never
computes a score of its own.

## Page structure

1. **Coverage matrix** (`#overview`) — every method against every protocol, all
   39 comparisons on the opening screen, server-rendered with no JavaScript.
   Bars are scaled against each protocol's own chance level, so they read down a
   column and not across one. No total column and no overall rank: the release
   deliberately has no cross-task score.
2. **Per-protocol panel** (`#benchmarks`) — all eight protocols as tabs, each
   with its cohort, electrode layout, training budget, source terms, limitations,
   chart and per-protocol CSV.
3. Model directory, dataset register, field notes and method notes.

`src/data/site.ts` is the single switch for the name, origin and public contact
address. `src/styles/` holds the palette and type scale; brand rasters are
regenerated by `scripts/generate-brand-assets.py` and read the name out of
`site.ts` so a rename cannot strand them.

## Working on it

```bash
npm run dev -- --background   # temporary local preview; stop with `astro dev stop`
npm run build                 # required before the check below
node scripts/check-workbench.mjs
```

`check-workbench.mjs` covers both halves: the client script through DOM doubles,
and the server-rendered matrix by re-deriving every cell from `mvp.json` and
comparing it against `dist/index.html`. See `VALIDATION.md` for what the tests
do and do not establish.

## Deploying

Cloudflare Workers Static Assets, configured in `wrangler.jsonc`, which pins the
upload scope to `./dist` — a dry run reports 28 files, exactly the set
`check_site_artifact.py` accepts.

```bash
npm run cf -- login     # one-time; opens a browser for you to authorise
npm run deploy          # uploads ./dist and nothing else
npm run cf -- <other wrangler command>
```

Use these scripts rather than bare `wrangler`: they set
`WRANGLER_SEND_METRICS=false`, which the `send_metrics` key in `wrangler.jsonc`
cannot fully do on its own (see the comment there). Never pass a directory
argument by hand — `site/.git.superseded-20260920` still contains
per-participant rows from an earlier export and must never be uploaded.

No backend, GPU, raw EEG, checkpoint distribution, telemetry SDK or automated
updater is involved.
